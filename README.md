# Weather-Check 🌦️

Weather-Check is a lightweight web app that lets you quickly check the current weather for any city. It fetches real-time data from the OpenWeather API and displays it in a simple, user-friendly interface.

---

## Features
- 🌍 Search weather by city name
- 🌡️ Current temperature
- 💧 Humidity levels
- 🌬️ Wind speed
- ☁️ Weather condition (Clear, Rain, Clouds, etc.)

---

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **API:** [OpenWeather](https://openweathermap.org/api)
